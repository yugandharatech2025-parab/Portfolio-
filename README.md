## About the project

This is the personal portfolio of **Yugandhara (ugAura)**, a web developer and designer. It introduces who I am, lists the services I offer, shows selected projects and shares my toolkit and contact details.

The goal was a clean, modern page that feels alive: bold typography, a single neon green accent, soft glow effects and smooth animations, without any framework or library.

## Features

- **Dark theme with neon green accent** used for highlights, glow and hover effects
- **Fully responsive** layout that adapts from small phones to large desktops
- **Smooth animations** on the hero text, a shining headline, a pulsing marker and a floating glow
- **Services grid** with 12 offerings, shown in 2, 3 or 4 columns depending on screen width
- **Project cards** with live demo and source links
- **Skill chips** for the full toolkit
- **Copy email button** built with JavaScript
- **SEO ready**: page title, meta description, keywords, Open Graph tags and structured data (JSON-LD)
- **Accessible**: semantic HTML, keyboard focus styles and reduced-motion support

## Run it locally

No installation or build step is needed.

```bash
# 1. Clone the repository
git clone https://github.com/yugandharatech2025-parab/Portfolio-.git

# 2. Open the folder
cd Portfolio-

# 3. Open index.html in any browser
```

## Customize

Change the green accent across the whole site by editing one line at the top of `style.css`:

```css
:root {
  --accent: #c8ff2e;   /* change this color */
}
```
